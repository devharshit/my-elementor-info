Displays Elementor (Pro) widget usage across your site: with color-coded counts, searchable admin table, author and date info, and a dashboard summary widget.

== Description ==

Gain deep insight into Elementor widget usage on your site with this admin utility:

* Display widget use counts
* Full admin table: Widget name, usage count, page title, page URL, widget date created (page publish date), and author
* Search any widget, page, or author
* Dashboard widget summary: just "Widget Name (Count)" and "Page Title"
* Uses native WordPress admin table styles for seamless UI

Perfect for agencies, site maintainers, and performance auditors.

== Installation ==

1. Upload the plugin `.zip` file into `www.site-url.com/wp-admin/plugin-install.php`.
2. Activate plugin.
3. Access the full report under **Dashboard > Elementor Widget Usage**.
4. See a summary widget on your WordPress admin dashboard.

== Frequently Asked Questions ==

= Who is shown as 'Created By'? =
The author of the WordPress page containing the widget.

= What does 'Widget Date Created' mean? =
The page's published date (when the widget was first added).

= Are private or draft pages included? =
No, only published pages show up by default.

= Does this work with Elementor Pro widgets? =
Yes! Free and Pro widget usage is reported.
